# Бюро погоды

Сказочная браузерная merge-игра. Объединяйте одинаковые предметы, собирайте дождь, свет и ветер и выполняйте просьбы жителей. Каждая доставка меняет сад или старую обсерваторию.

## Что есть в игре

- Две главы по пять сюжетных писем и дополнительное письмо.
- Погодный атлас, полка на три предмета и отмена хода.
- Карта, журнал и сравнение локаций до и после изменений.
- Настройки звука и движения, управление мышью, касаниями и клавиатурой.

Прогресс хранится в браузере на этом устройстве. Сохранения с другого адреса сайта автоматически не переносятся.

## Запуск

Игра работает на GitHub Pages без сборки, сервера приложений, установки зависимостей и ключей доступа. В настройках репозитория откройте Settings → Pages и выберите Deploy from a branch → main → / (root).

Для локального просмотра запустите в папке с index.html команду `python -m http.server 8000 --bind 127.0.0.1` и откройте http://127.0.0.1:8000/.
